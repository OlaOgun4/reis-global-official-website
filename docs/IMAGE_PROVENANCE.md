# REIS Global Website Image Provenance

## Version 2 project backgrounds

The seven project-page backgrounds in `public/images/projects/` were generated specifically for the REIS Global Website on 18 August 2026 using OpenAI image generation.

- No third-party stock images were used.
- No external reference images were supplied.
- Prompts prohibited logos, trademarks, flags, official insignia, readable text, watermarks and identifiable people.
- The resulting images were reviewed for those prohibited elements before inclusion.
- Images are decorative website backgrounds and are not evidence of a deployed facility, client environment or implemented technical architecture.
- Images were converted to compressed WebP assets with metadata stripped.

| `farm-naturale.webp` | Integrated agricultural learning and participation |
